# Homebrew tap for ProxyDog

```sh
brew tap babaktaremi/tap
brew trust babaktaremi/tap      # Homebrew 7+ asks you to trust a third-party tap once
brew install --cask proxydog
```

Update with `brew update && brew upgrade --cask proxydog`.

The cask follows the latest [ProxyDog](https://github.com/babaktaremi/proxydog) release.
